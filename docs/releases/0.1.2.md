# Mogestrator 0.1.2 — stable M1

This release completes M1 on the stable line. The package page now points to the
renamed [Mogestrator repository](https://github.com/prayag2301/Mogestrator).

## Changes

- `mog search` finds local full-text matches and returns content anchors with
  `--json`. It is an M1 text search command; graph retrieval remains in M2.
- The index now links conservative imports and bounded Git co-change pairs.
- Identical symbol bodies retain continuity across file renames.
- Schema v3 uses compact contentless FTS and migrates existing indexes.
- Documentation and package metadata reflect the completed M1 scope.

## Install

```bash
pip install mogestrator==0.1.2
mog index
mog search "token" --json
```

Python 3.11 or newer is required. Existing `.mog/graph.db` files migrate on
first open. Keep a backup if you need to reopen an index with 0.1.1, since that
version cannot read schema v3.
