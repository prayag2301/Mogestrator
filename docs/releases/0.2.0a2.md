# Mogestrator 0.2.0a2

This prerelease completes the M1 indexing roadmap while keeping retrieval and MCP experimental. The M2 quality gate remains open.

## Changes

- Link unambiguous local imports across Python, TypeScript/JavaScript, Go, and Rust files.
- Mine recurring symbol co-changes from recent Git diffs with bounded support and fan-out.
- Carry anchored facts through unique symbol and file renames when the normalized body matches.
- Move to contentless FTS5 in schema v3. Existing indexes migrate in place and are compacted; episodic memories are preserved.
- Avoid loading all symbols during unchanged reindexing.

On pinned Django, a fresh index of 1.05 million indexed lines took 18.23 seconds and occupied 369% of indexed source, below the revised 400% target. With 200 commits, a full rebuild took 29.06 seconds and produced 44 directed co-change edges. See [the benchmark](../results/m1-index-2026-09-25.md) for conditions and limitations.

Install with `pip install --pre "mogestrator[mcp]==0.2.0a2"` or `uvx --from "mogestrator==0.2.0a2" mog`.
